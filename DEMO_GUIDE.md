# Cabin workspace — current review guide

Choose/resume aircraft information, then configure/load through the image. Role sets a starting fit, not a restriction to that role's equipment. Select installed items for controls or cells for location choices; Area options returns to the underlying location. Four individual Cargo slots and separate per-bay/Ramp weight entries remain independent.

Live equipment follows installed state. Reference mode shows original pictures. The Sea Tray is selectable through five occupied cells (B3/B4 Centre and Stbd, B5 Centre); its removed label sits on the pictured tray. C3 has normal controls but no position-review editor. Seats/Occupants visibility changes do not alter mass.

Detail imagery follows DETAIL_IMAGE_APPLICABILITY_2026-10-28.md: all for SAR-3; Cabinet/Forward/Ramp for SAR-10; Forward/Ramp for Transport/CASEVAC. Grey choices explain why a picture is unavailable. Equipment/contents and W&B remain usable. Ramp image is representative but lacks permanent P2/P3, a future visual correction.

Fuel supports the existing automatic/manual source model and Fuel at landing (reserve). CG gives live takeoff/estimated-landing feedback with non-fuel loads held unchanged. Numeric display rounds kg/mm while calculations retain precision. Standard occupant weights are intended. Compatible sessions persist locally. Role reset confirms configuration/loading changes while retaining aircraft/fuel; navigation alone does not reset the aircraft.

One finger scrolls page, two fingers move/zoom image; Reset centers at 100%. This is a development/device-review prototype, not completed operational acceptance. Current source status, tests and limitations are in the handoff and verification report.
